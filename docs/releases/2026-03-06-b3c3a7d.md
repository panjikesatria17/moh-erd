# Release Notes - 2026-03-06 (`b3c3a7d`)

## Ringkasan

Rilis ini memfinalkan peningkatan besar modul procurement, mencakup workflow dana pembelian, notifikasi approval owner, hardening upload bukti, ekspor laporan, perluasan master data, PDF dokumen operasional, serta penyelarasan akses role pada UI dan API.

## Fitur Utama

- Menambahkan workflow `purchase_funding_requests` end-to-end: submit, review finance, approval owner, disburse, settlement.
- Menambahkan notifikasi database untuk pengajuan dana yang menunggu approval owner.
- Menambahkan ekspor laporan pengajuan dana ke Excel dan PDF.
- Menambahkan hardening upload untuk bukti pembayaran, bukti delivery, bukti reject item, dan bukti settlement.
- Menambahkan modul kwitansi gabungan invoice vendor (create + PDF).
- Menambahkan modul pencatatan barang reject beserta foto bukti.
- Menambahkan scope API berbasis role (`sppg_user`, `vendor_admin`) dengan trait reusable.
- Menambahkan/menyempurnakan PDF dokumen: PO, PR, invoice, surat jalan, rekap invoice, master produk, laporan funding.
- Menambahkan CRUD lengkap pada beberapa master data (SPPG, vendor, product, price history, users-roles).

## Perubahan Database

- Menambah tabel baru:
    - `purchase_funding_requests`
    - `rejected_items`
    - `kwitansis`
    - `kwitansi_invoice`
    - `app_settings`
    - `notifications`
- Menambah kolom/indeks baru pada beberapa tabel penting:
    - `products` (harga, varians, vendor, ad-hoc)
    - `deliveries` (proof fields, invoiced amount)
    - `payments` (proof + approval fields)
    - `purchase_requests` (additional flags)
    - `vendors` (owner_name)
    - `sppgs` (signers)
    - `purchase_funding_requests` (settlement proof fields)

## Akses & UI

- Menyelaraskan matrix akses role UI/API dan mendokumentasikannya di `docs/ROLE_ACCESS_MATRIX.md`.
- Menambahkan penyesuaian tampilan dashboard per role.
- Menambahkan aset branding (favicon/background/logo vendor) untuk pengalaman UI/PDF yang lebih konsisten.

## Verifikasi

- Full test suite: `66 passed`, `325 assertions`.
- Build frontend: sukses (`npm run build`).

## Catatan Operasional

- Pastikan migrasi dijalankan di environment target sebelum deploy:

- Jika diperlukan data awal role/master, jalankan seeder sesuai prosedur proyek.
