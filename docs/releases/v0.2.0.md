# v0.2.0 — UI Dashboard Actionable Flows and Feature Tests

Release date: 2026-03-01
Tag: v0.2.0

## Highlights

- Menambahkan UI web procurement berbasis Blade untuk operasional HO.
- Menambahkan action langsung dari UI untuk alur utama procurement.
- Menambahkan test fitur untuk memvalidasi alur UI end-to-end.

## What’s Included

### UI Web Modules

- Dashboard ringkasan procurement (SPPG, vendor, PR, PO, invoice, stock alert).
- Halaman daftar:
    - Purchase Requests
    - Purchase Orders
    - Deliveries
    - Invoices

### Actionable UI Flows

- Create Purchase Request dari halaman Purchase Requests.
- Approve Purchase Request dari tabel PR.
- Generate Purchase Order dari PR yang sudah approved.
- Generate Invoice dari Delivery yang eligible.
- Notifikasi sukses/error ditampilkan di layout UI.

### Routing

- Menambahkan route UI baru di prefix `/ui`:
    - `/ui/dashboard`
    - `/ui/purchase-requests`
    - `/ui/purchase-orders`
    - `/ui/deliveries`
    - `/ui/invoices`
- Menambahkan route POST untuk aksi UI:
    - create PR
    - approve PR
    - generate PO
    - generate invoice

### Testing

- Menambahkan test baru `ProcurementUiFlowTest` untuk skenario:
    - dashboard accessible
    - create PR -> approve PR -> generate PO dari UI
- Menyesuaikan test default root endpoint agar sesuai behavior redirect ke dashboard UI.
- Status test suite: PASS.

## Developer Notes

- Release ini fokus pada usability internal web UI dan validasi alur minimum.
- API, database schema, seeder, auth Sanctum, serta Postman collection/environment tetap kompatibel dengan release sebelumnya.

## Suggested Next Iteration (v0.3.0)

- Form detail multi-item PR di UI (bukan quick form 1 item).
- Role-based UI visibility per menu dan per action.
- Halaman detail dokumen (PR/PO/Invoice) dengan timeline approval dan audit trail.
- Export PDF dokumen (PO, surat jalan, invoice).
- Dashboard KPI vendor performance dan aging invoice.
